Task 2 - Feature Engineering & Model Comparison

📌 Project Overview
This project improves the machine learning pipeline by applying feature scaling and comparing multiple regression models using the California Housing dataset.

🧠 Steps Performed
Data Loading
Feature Scaling (StandardScaler)
Train-Test Split
Model Training (Linear Regression, Ridge Regression, Decision Tree)
Model Evaluation (RMSE, R²)
Model Performance Comparison
Visualization (Actual vs Predicted)

📊 Results
Models were compared using RMSE and R² score.
Decision Tree / Ridge / Linear Regression performance was analyzed to identify the best model.

Python
Pandas
NumPy
Scikit-learn
Matplotlib
Jupyter Notebook
